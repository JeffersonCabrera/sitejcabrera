# Reportar un problema de seguridad

Si detectas un problema de seguridad en [jeffersoncabrera.com](https://jeffersoncabrera.com/), comunícalo de forma privada a [jeffersoncabreradev@gmail.com](mailto:jeffersoncabreradev@gmail.com).

Incluye la dirección afectada y una descripción que permita revisar el problema. Evita publicar credenciales, datos personales o información sensible en incidencias públicas.
